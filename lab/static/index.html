Zero-filled sparse FITS. Tests network and Streamer throughput, not physical disk read performance. Data is received and discarded in bounded memory; this browser test does not save a file. No full-file SHA-256 has been computed.

全量传输约 1 TB，会消耗服务器公网流量，可能产生费用。默认测试最多 256 MiB / 30 秒。不要用普通下载按钮下载大文件。

No transfer started.

To save the FITS file or run a longer test, download the Python client. It prompts for the laboratory password; its default is a 256 MiB sample discarded without saving.

python3 download_large.py
# Full transfer, discard bytes (uses ~1 TB of network traffic):
python3 download_large.py --full --confirm-1tb
# Full transfer, save to disk (requires >1 TB free):
python3 download_large.py --full --confirm-1tb --output large-1tb.fits
